### 1.4 配置面板首次加载 pills 为空

- **修复**：loadGalaxy 完成后自动调 loadKgConfig()

### 1.5 边标签按缩放级别显隐

## 四、稳定性/架构 (5 项)

### 4.1 HNSW 死 ID 定期清理
- **现状**：删除记忆后向量索引残留死 ID（search 后取不到数据跳过，功能不影响但膨胀）
- **修复**：EvictionService 每次清理后调 memory_index.rebuild()（重建索引剔除死 ID）。或标记 deleted 在 search 后过滤。
- **文件**：`services/eviction.py` + `engine/vector_index.py`
- **改动量**：20 行（重建较重，可选"标记+过滤"轻量方案）

### 4.2 tag_relations.created_at NULL 补全
- **现状**：部分旧 tag_relations 没有 created_at，时间范围过滤不完整
- **修复**：一次性 UPDATE tag_relations SET created_at = (SELECT MIN(m.timestamp) FROM memories m JOIN memory_tags mt ON m.id=mt.memory_id JOIN tags t ON mt.tag_id=t.id WHERE t.id=source_tag_id) WHERE created_at IS NULL
- **文件**：运行时 DB migration 或手动脚本
- **改动量**：1 条 SQL

### 4.3 jargon 预热性能
- **现状**：预热 20000 条约 2s，消息量大时启动慢
- **修复**：限制预热 LIMIT 10000 + 只取最近 3 天（缩小范围但保持效果）
- **文件**：`services/jargon/service.py` _warmup_from_memories
- **改动量**：改 2 个参数

### 4.4 wave_memory.db 体积监控
- **现状**：1.7GB 单文件无预警
- **修复**：/api/system 返回 db_size_mb；概览页显示；超 2GB 时警告
- **文件**：`webui/blueprints/system.py` + `webui/static/index.html`
- **改动量**：10 行

### 4.5 consolidation 与 belief_engine 初始化顺序保护
- **现状**：依赖 consolidation 先实例化(505行)再赋值 belief_engine(697行)
- **修复**：加 assert 或防御性检查；注释说明顺序约束
- **文件**：`main.py` 697 行附近
- **改动量**：3 行注释 + 1 行 assert
